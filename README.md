# davidmackay709.github.io

Personal website and portfolio, built with [Astro](https://astro.build) and hosted on GitHub Pages.

Live at **https://davidmackay709.github.io**.

## How it deploys

Every push to `main` runs [.github/workflows/deploy.yml](.github/workflows/deploy.yml), which builds the site and publishes it to GitHub Pages. Check the **Actions** tab for build status.

## Local development (optional, needs Node.js)

```sh
npm install
npm run dev
```
